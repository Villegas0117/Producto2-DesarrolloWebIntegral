# Comandos de prueba

## Node.js

```bash
cd node/01_soap_ingles
npm install
npm start
curl "http://localhost:3001/?n=10"
```

## Ruby

```bash
cd ruby/01_soap_ingles
ruby app.rb
curl "http://localhost:3011/?n=10"
```

## Perl

```bash
cd perl/01_soap_ingles
perl app.pl
curl "http://localhost:3021/?n=10"
```

## .NET 10

```bash
cd dotnet10/01_soap_ingles

```

## Golang

