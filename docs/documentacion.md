# Documentación del proyecto

## Introducción

El presente proyecto implementa aplicaciones del lado del servidor en diferentes lenguajes de programación. Cada lenguaje contiene tres versiones relacionadas con la conversión de números a letras.

## Caso de estudio

El caso de estudio se basa en el consumo del servicio web SOAP público:

```text
https://www.dataaccess.com/webservicesserver/NumberConversion.wso?WSDL
```

## Versiones desarrolladas

1. Consumo del servicio SOAP y respuesta en inglés.
2. Consumo del servicio SOAP y traducción del resultado a español.
3. Conversión local de número a letras en español.
